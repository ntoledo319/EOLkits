Lambda Node.js 22 projected create/update restrictions

AWS Lambda — published migration milestone

2027-06-01

270 days until the 2027-06-01 deadline — enough runway to migrate safely.

What is being deprecated?

Node.js 22 Lambda runtime (Amazon Linux 2023) has a projected deprecation date of 2027-04-30. AWS currently projects blocking new nodejs22.x functions on 2027-06-01 and updates on 2027-07-01; AWS marks runtime dates as subject to change.
