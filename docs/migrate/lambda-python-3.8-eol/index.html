Lambda Python 3.8 create/update restrictions

AWS Lambda — published migration milestone

2027-07-29

252 days until the 2027-07-29 deadline — enough runway to migrate safely.

What is being deprecated?

Python 3.8 Lambda runtime (Amazon Linux 2) deprecated 2024-10-14. Per the AWS Lambda runtime deprecation table, AWS blocks creating new python3.8 functions on 2027-07-29 and updating existing ones on 2027-08-31.

Migration checks

When moving away from this runtime or operating-system release, verify these configured concerns in your own workload. A listed concern is not proof that every workload is affected. [provider status source]

  • Upgrade target is python3.12 (3.13 available)
  • distutils and imp removed in 3.12 (fix on upgrade)
  • collections ABCs moved to collections.abc (3.10+)
  • Native wheels may need version bumps for cp312 on AL2023
