About EOLkits

EOLkits builds deterministic static analysis, migration codemods, and source-cited reference guides for teams upgrading off deprecated AWS Lambda runtimes and Amazon Linux 2.

Engineering principles

  • Primary sources only: Every tracked deprecation milestone links directly to official AWS documentation, Python PEPs, or Node.js release notes—never recycled secondary blog posts.
  • Deterministic output: Running the same scanner and rule pack on the same source tree produces identical findings and SHA-256 evidence hashes.
  • Zero-upload options first: Both our free browser scanner and the $79 Offline Migration & Audit Toolkit run locally so proprietary company source code never leaves your environment.
  • Explicit scope boundaries: Static scanners inspect supplied source, IaC, and manifests; they never fabricate live cloud resource counts or speculative downtime-dollar claims.

Products & licensing

  • Open-source CLIs ($0, MIT): al2023-gate, python-pivot, and lambda-lifeline on GitHub.
  • Offline Migration & Audit Toolkit ($79 USD): Instant-download commercial ZIP pack with unified air-gapped repo/IaC scanner, HTML/PDF + Jira CSV reports, Python 3.12/3.13 & AWS SDK v3 codemods, AL2023 Dockerfiles, and canary rollback IaC. Licensed for unlimited internal repositories of the purchasing individual or company.
  • Hosted Repository Evidence Report ($299 USD): Server-gated static scan of one uploaded repository ZIP returning a 4+ page PDF and 30-day /verify/ hash lookup.
