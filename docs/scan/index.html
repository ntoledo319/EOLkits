File coverage

    Know the scope

    A useful first check. A bounded one.

    What it checks

    • Configured Lambda runtime declarations in AWS infrastructure and source files.
    • Tracked Node native packages against conservative compatibility baselines; meeting one still requires target-runtime testing.
    • Tracked Python dependencies for Python 3.12 wheel baselines in requirements files and PEP 621 dependency lists.

    What it does not establish

    • No AWS account access, live inventory, runtime execution, or automatic code changes.
    • No full syntax validation of YAML, HCL, or TOML, complete repository coverage, resolved lockfiles, or recursive requirements includes.
    • A match is a review task. No matches does not prove migration readiness. Provider dates can change; follow the source links.

    File names and contents are not uploaded. If the verified v2 telemetry service is available, bounded aggregate counts may be sent (only file and finding counts). Privacy details.
