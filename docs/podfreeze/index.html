CocoaPods trunk freeze

This page mirrors the podfreeze project, an open-source (MIT) CLI that reads the SPEC REPOS section of your Podfile.lock and reports which pods resolved from CocoaPods trunk — the coordinates that can never receive another published version, including a security fix.

Project, browser checker and source: podfreeze on GitHub.

The CocoaPods maintainer’s plan: from 2 December 2026, trunk stops accepting new podspecs, permanently. The maintainer’s plan set a read-only test run for 2–6 November 2026.

Existing builds keep resolving from the Specs repo on GitHub and the jsDelivr CDN, so the freeze is a supply-chain event rather than a build break: a pod with a newly discovered vulnerability has no canonical coordinate to carry the fix.

Moving off CocoaPods? Send your Podfile.lock: every pod inventoried and a written fixed-scope migration quote. Start a brief. No price is quoted before the scope is agreed in writing.

Source: CocoaPods Trunk Read-only Plan — the maintainer’s own announcement.
