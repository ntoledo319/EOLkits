# Archived Gumroad experiment

No Gumroad product is approved, built, or available from this repository. The
old proposal repackaged freely available code, depended on obsolete claims, and
did not justify a paid bundle. Its builder was removed so it cannot be listed by
mistake.

The remaining documents are historical records only. Do not upload or sell
them. The approved commercial direction is the evidence-producing Audit v2
described in [`revenue/PLAN.md`](../../revenue/PLAN.md).
